### G3-GPT - AI-Driven Document Retrieval Platform
**Senior Capstone Project** | **Repository**: [G3-GPT](https://github.com/trangt202/G3-GPT) *(Private)*

An intelligent Retrieval-Augmented Generation (RAG) platform designed for G3 Enterprises, a global family-owned supply chain company. This AI-powered application serves as a virtual help desk, providing secure, role-based access to internal documents with accurate, context-aware responses. Built as a full-stack solution with enterprise-grade authentication and document management.
